# NOCTURNE — Digital Atelier

Concept portfolio site for a fictional digital atelier. Dark editorial art direction, high‑contrast serif typography,
cinematic motion. React 18 + TypeScript + Vite + GSAP (ScrollTrigger, CustomEase). No 3D runtime, no UI kit.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build → dist/
npm run preview    # serve dist/ on http://localhost:4173
npm run build:static  # hash-routed build with relative paths → dist-static/ (any static host, no rewrites)
```

## What's inside

| Route | |
| --- | --- |
| `/` | Intro → Manifesto → Selected projects → Colophon |
| `/projects/:slug` | Project detail (`visual-identity`, `branding`, `3d-motion`, `art-direction`) |
| anything else | 404 page (unknown project slugs too) |

```
src/
  config/site.ts          ← name, tagline, disclaimer
  data/projects.ts        ← all project copy, palettes, galleries
  data/art-manifest.json  ← generated by `npm run art:optimize`
  lib/gsap.ts             ← GSAP setup, house easings, reduced-motion / pointer checks
  lib/useGsap.ts          ← gsap.context hook; every tween & ScrollTrigger is reverted on unmount
  styles/tokens.css       ← colour, type scale (clamp), spacing, easing tokens
  components/
    Header/               ← top bar, hide-on-scroll, fullscreen menu (focus trap, Esc)
    Hero/                 ← intro sequence + scroll parallax
    Manifesto/            ← about / editorial composition
    Projects/             ← asymmetric project grid
    ProjectDetail/        ← project page template
    Colophon/             ← disclaimer + project credits, intensity fade
    Transition/           ← page curtain + image-expand transition, onEnter hooks
    CustomCursor/         ← dot + ring, "View project" state (mouse only)
    Art/                  ← responsive AVIF/WebP <picture> with placeholder
    Mask/                 ← line/char masks for text reveals
tools/
  artgen/                 ← procedural image generator (GLSL raymarcher in headless Chromium)
  optimize-images.mjs     ← AVIF/WebP 800/1600/2400w + manifest + grain tile
  smoke.mjs               ← Playwright smoke test (desktop/tablet/mobile, console errors, overflow, routes)
```

## Disclaimer

NOCTURNE is fictional. This is a concept portfolio piece: the studio, clients, projects and quotes are invented,
and the site collects no data (no forms, no contact details, no tracking). The closing **Colophon** section and the
footer say so on the page; the wording lives in `src/config/site.ts`.

## Imagery

The images are original, generated by `tools/artgen` (raymarched monochrome scenes: veiled figure,
marble head, monolith, black chrome, metal flower, colonnade), so the concept ships without third-party photos.

- Re-render: `npm run art:render` (needs Playwright's Chromium), then `npm run art:optimize`.
- Use real photos: drop `<slot>.jpg|png|webp` into `art-source/` and run `npm run art:optimize`.
  Slots and briefs are listed in [`art-source/README.md`](art-source/README.md).

## Motion & accessibility

- Intro plays once per visit; later visits to the home page get a short reveal.
- Native scrolling, no scroll-jacking. Scroll animations are scrubbed or `once`.
- `prefers-reduced-motion`: intro, parallax, reveals and page transitions are turned off; grain stays still.
- Custom cursor only on `(hover: hover) and (pointer: fine)`; the native cursor is kept elsewhere.
- Skip link, visible `:focus-visible` states, real `<a href>` for every link (cmd/ctrl‑click opens a new tab).

## Deploy

It's a static SPA. Unknown paths have to fall back to `index.html` — `public/_redirects` (Netlify) and
`vercel.json` (Vercel) are included. Other hosts need the same rewrite.
